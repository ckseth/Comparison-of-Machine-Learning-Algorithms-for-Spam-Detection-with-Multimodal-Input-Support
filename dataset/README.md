# Datasets

This directory contains the datasets utilized and evaluated in this research:

1. **SMS Spam Collection Dataset (`SMSSpamCollection`)**:
   - Source: UCI Machine Learning Repository / Tiago A. Almeida and José María Gómez Hidalgo.
   - Total Messages: 5,574 SMS messages tagged as either `ham` (legitimate) or `spam`.
   - After duplicate removal and cleaning: 5,169 distinct instances.
   - Format: Tab-separated values (`label\tmessage`).

2. **`sms+spam+collection.zip`**:
   - Original UCI archive documentation and distribution.

3. **`spambase.zip`**:
   - UCI Spambase dataset archive containing email spam frequency attributes, documentation, and metadata.
